# C Programming Practice 💻

Welcome to my dedicated workspace for mastering C Programming! This repository is focused on building a strong foundation in logic building, problem-solving, and core software engineering concepts. 

Instead of just running code, my goal here is to deeply understand how data structures, operators, and memory management functions work under the hood.

---

## 📌 Core Concepts Covered

Here is the list of algorithmic and programmatic concepts implemented in this repository:

### 🔹 Basic Logic & Math Operations
* **Simple Calculators & Swapping:** Programs demonstrating how to handle inputs, perform calculations using `switch-case`, and swap values with or without temporary variables.
* **Basic Properties:** Testing whether numbers are even/odd, positive/negative, finding absolute values, and identifying leap years.

### 🔹 Control Flow & Iterations
* **Loop Structures:** Practicing control loops (`for`, `while`, `do-while`) by printing sequences from $1$ to $N$ and handling standard multiplication tables.
* **Digit Operations:** Algorithms to extract, count, and sum digits within a given integer value.

### 🔹 Advanced Number Theory (Logic Building)
* **Prime & Perfect Numbers:** Implementations to check primality conditions and evaluating perfect numbers.
* **Armstrong & Fibonacci Sequences:** Code tracking specific number behavior, series expansions, and numerical properties.
* **G.C.D & L.C.M:** Finding the Greatest Common Divisor and Least Common Multiple using clean logical conditions.
* **Palindrome & Strong Numbers:** Reversing integers and validating patterns using robust algorithmic loops.

### 🔹 Modular Programming & Arrays
* **Functions & Recursion:** Organizing clean code block execution and modular components for operations like power calculation and number analysis.
* **Array Manipulations:** Storing linear items, computing sums, analyzing averages, and reversing element order dynamically.

---

## 🛠 How to Run These Programs

To compile and run any `.c` source file locally on your system, execute the following industry-standard command in your terminal:

```bash
gcc filename.c -o output && ./output
```
